麻將計分器

Mahjong Score Counter

角色 UI/UX 設計師
時間 2026
類型 Web 應用程式（Web App）
01

專案概述

Project Overview

一套可以簡單記錄金額
與胡牌、放槍等次數的系統

這是一個從前期構想、中期設計，到後期部屬上線，都由我「一人」所做的完整專案。

可以簡單記錄每局的胡牌、放槍或自摸人員，並統計次數。此外還可以記錄每將打完四個人的輸贏金額，最後結束遊戲時呈現今天遊玩下來的結算排行榜。

02

設計過程

Design Process

01

構想 CONCEPT

思考整套系統需要的模組與功能，並產出規劃文件。

02

線框稿 WIREFRAME

將規劃文件提供給AI，請AI工具協助產出線框稿，並隨時溝通修正。

03

設計 DESIGN

建構完備的元件設計系統。進行中高保真介面刻畫。

04

部屬 DEPLOY

請AI工具協助將系統建置在雲端網頁託管與開發平台。

03

設計展示

Design Deliverables

即時次數統計與記錄

每局完畢後立即進行胡牌、放槍或自摸的記錄，儀錶板清楚顯示四個人當前的各項次數統計，以及行為紀錄。

結算排行榜

遊戲結束後，系統自動統計最終金額、次數等，並進行排名。以及根據次數統計出放槍王、胡牌王等等，增加趣味性。

04

技術細節

Tech Stack & Challenges

使用的技術與工具

Figma Claude VS Code Supabase Netlify

技術挑戰與解決方法

我希望除了記錄者以外，其他人也能「即時」查詢當下的次數統計與分數，這部分就需要有「後端」幫忙建置後台、儲存資料，但後端不是我熟悉的領域。

另外，系統也需要有網域才能供大家使用，否則永遠只是在本機端運作。

我使用AI協作工具：Claude + VS Code，利用Prompt提示詞，一步一步請AI幫我做好後台的建置，以及雲端網頁的部屬。
